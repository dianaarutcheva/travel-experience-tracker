# travel-experience-tracker

An Android app built using Kotlin in Android Studio. It allows users to record and manage their travel experiences.

## Features

- Add experiences with a title, description, country, city, type, date visited and rating.
- View experiences in a list.
- Edit and delete experiences.
- Search experiences by name.
- Select Landmark, Restaurant or Activity using a dropdown.
- Choose the date visited using a calendar picker.
- Icons and a consistent colour scheme across the app.

## AI Usage

I used ChatGPT for help with implementing the search feature, type dropdown and calendar picker, and for guidance on some aspects of the app’s design.
